Bookstore API

Backend (funciones de Netlify) del bookstore. Ejemplos:

  • /.netlify/functions/bookFindAll
  • /.netlify/functions/authorFindAll
  • /.netlify/functions/publisherFindAll
  • /.netlify/functions/bookTasks (procesa la cola bookstore)
  • /.netlify/functions/authorTasks (procesa la cola authors)
  • /.netlify/functions/publisherTasks (procesa la cola publishers)
